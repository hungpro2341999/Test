# Sừng Chiến

Game 3D trên trình duyệt: điều khiển con dê trên đỉnh cột đá tròn, lấy đà húc đàn dê địch rơi xuống vực.

**Chơi ngay:** https://hungpro2341999.github.io/Test/

- Giữ chuột trái và rê như cần điều khiển (điện thoại: chạm và kéo).
- Chế độ test: phím 1–7 thả từng loại dê.
- Chơi theo màn: 10 màn, mỗi màn 1–2 loại dê.
